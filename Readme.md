# Учебные landing-страницы

Небольшой учебный проект, созданный для практики вёрстки адаптивных landing-страниц. В проекте представлены главная страница ресторана `Rest` и отдельная страница подтверждения бронирования.

## Страницы

### `index.html`

Главная landing-страница ресторана изысканной кухни `Rest`. На странице есть:

- шапка с логотипом, навигацией и кнопкой бронирования;
- первый экран с призывом забронировать столик;
- блок авторского меню с карточками блюд и винной карты;
- форма бронирования с обязательными полями;
- уведомление об использовании cookie-файлов;
- подвал с навигацией и контактами.

После заполнения формы пользователь переходит на страницу `thanks.html`.

### `thanks.html`

Страница подтверждения бронирования с сообщением «Благодарим за бронирование в ресторане Rest!». Она оформлена в едином стиле с главной страницей и содержит:

- шапку ресторана `Rest` с навигацией и кнопкой бронирования;
- подвал с меню, контактным телефоном, электронной почтой и адресом ресторана;
- информацию о ресторане изысканной кухни и копирайт `Rest`.

## Технологии

- HTML5 и семантическая разметка;
- CSS3, адаптивная вёрстка и медиазапросы;
- нативный JavaScript для мобильного меню и cookie-уведомления;
- FormSubmit для обработки формы бронирования;
- SVG-спрайт для иконок;
- изображения в форматах JPG и WebP;
- методология именования классов БЭМ.

## Структура проекта

```text
.
├── index.html              # Основная страница ресторана
├── thanks.html             # Страница подтверждения
├── scripts.js              # Интерактивные элементы
├── styles.css              # Точка подключения стилей
├── styles/                 # Стили по компонентам страницы
└── images/                 # Изображения, favicon и SVG-спрайт
```

## Запуск

Проект не требует сборки и зависимостей. Откройте `index.html` в браузере или запустите локальный статический сервер из корня проекта.

Например, через расширение Live Server в VS Code.

## Ограничения учебной версии

Форма работает как демонстрационный сценарий: данные не отправляются на сервер, а после прохождения встроенной HTML-валидации выполняется переход на `thanks.html`. Ссылки навигации и политика конфиденциальности пока являются заглушками.
